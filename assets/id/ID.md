# ID do Jhon (/ojhon)

Mesmo sistema da ID do Gab (/ogab): fundo quase preto, uma cor neon de assinatura com degradê, marca em Inter Tight 800. O Gab é verde; o Jhon é azul elétrico (resultado, painel, dado).

| Token | Valor | Uso |
|---|---|---|
| Fundo | `#060A14` / `#111A2E` | banner, telas escuras |
| Azul do Jhon | `#2F6BFF` | cor de assinatura, botão principal, aba ativa |
| Degradê da marca | `#9DBBFF` > `#2F6BFF` | palavra "/ojhon" |
| Degradê do símbolo | `#5C8DFF` > `#1E3FD8` | quadrado do símbolo |
| Apoio | `#E9EFFF` (fundo azul claro), `#1B2B8F` (marinho) | faixas e textos sobre azul |
| Semânticas | bom `#12B76A`, atenção `#F79009`, ruim `#F04438` | selos do parecer |
| Fonte da marca | Inter Tight 800 (`assets/fontes/InterTight`, OFL) | "/ojhon", títulos grandes |
| Fonte de texto | Inter 400/500/600 | painel, tabelas |

Símbolo: quadrado arredondado azul com três barras subindo e uma seta de tendência (tráfego que cresce). Arquivos: `jhon_marca.svg` (símbolo), `jhon_logo.svg` (símbolo + "/ojhon"), `.github/banner.svg` (banner do repositório). O painel (`painel/index.html`) usa o mesmo símbolo e as mesmas cores.
